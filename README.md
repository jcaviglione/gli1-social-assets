# GLI1 Social Assets

Repositorio publico de imagenes finales aprobadas para redes sociales de GLI1.

No subir proyectos Revit, informes de clientes, credenciales, borradores confidenciales ni contenido interno.

Los assets se exportan en JPEG para compatibilidad con Instagram y se verifica la ausencia de metadatos personales (EXIF/GPS/editor). La procedencia visual y las declaraciones aplicables sobre uso de IA se gestionan de forma transparente.

Origen editorial: GLI1 - Community Manager en Google Drive.
